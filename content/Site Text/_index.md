Shared navigation, buttons, filters, accessibility labels, and system messages live in this folder. Edit their values in Obsidian and the site uses them on the next build. Keep the key names unchanged. Page introductions, headings, descriptions, captions, credits, and editorial links live in the corresponding note bodies.
