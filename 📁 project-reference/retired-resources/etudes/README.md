# Retired Études Resources

Tim requested removal of the whole Études section on October 21, 2026.

- `pages/` preserves the seven Markdown files formerly in `content/resources/etudes/`.
- `files/` preserves the six PDFs and CSV formerly in `static/media/resources/etudes/`.

These files are outside Hugo's content and static folders, so they are excluded from the public site. Restore each folder to its former location to restore the section.

The seven retired page addresses are explicitly recorded in `scripts/retired-addresses.json`. The publish address checker permits these exact removals. Other missing addresses, including any other path under `/resources/etudes/`, still fail the check.
