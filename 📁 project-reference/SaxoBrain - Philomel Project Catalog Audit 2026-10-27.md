# Philomel Project Catalog Audit

Checked October 27, 2026. Scope: all 41 works in Tim’s pasted saxophone selection from [The Philomel Project: Women Composers Database](https://www.philomelproject.com/).

## Result

Sixteen works already had catalog records. Added the other twenty-five works and sixteen supporting composer profiles. Existing files and permanent addresses were preserved. Difficulty ratings remain blank for all new works. This checks inclusion of the supplied selection; it does not claim a complete audit of the entire Philomel website or of each composer’s output.

### Charlotte Bray: Circling Point

- [Source 1](https://charlottebray.co.uk/works/chamber/circling-point/)
- [Source 2](https://www.fabermusic.com/shop/circling-point-d44086)

- [Source 1](https://www.billaudot.com/saxy-3.html)
