# Composer Profile Research: Batch A

Verified 28 October 2026. Private project-reference evidence for 11 newly added composer profiles. Nationality uses explicit descriptors. Born and died are integer years in public metadata. Death years remain blank because no death is documented in the reviewed biographies.

All 11 selected local portraits were visually inspected in a contact sheet. David Dean Mendoza’s first image candidate was a poster and was replaced before any content edit with the direct headshot on his biography page.

## Unresolved Fields

- Chia-Yu Hsu: birth year conflict, 1971 versus 1975; public born remains blank.
- David Dean Mendoza: nationality remains blank because searched sources did not explicitly establish it.
