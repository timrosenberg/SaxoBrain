## Identity and Version Decisions

- Hsu Chiayu is cataloged as Chia-Yu Hsu. Composer website and NewMusicShelf identify that name.
- James Diaz is cataloged as James Díaz. The composer uses the accented spelling.
- Auerbach Prayer uses four alternative saxophone editions in one catalog record. The composition year property records the first saxophone version, 2009.
- Cheung solo Nyanse is distinct from Nyanse I for string quartet.
- Cardinal requires reverb.
- Kakia Gkoudina Three Women has a soprano listing in Noa Even and a later tenor with actors performance. Score availability and version scope remain unknown.
- Existing Balter Wicker Park soprano instrumentation was preserved because the existing note records Tim’s explicit instruction. The composer catalog currently says alto.
