# Composer Profile Research: Batch C

Verified 28 October 2026. Private evidence for ten newly added composer profiles. Nationality uses explicit national descriptions or citizenship statements. Born and died use integer years in public metadata. Death fields remain blank because the reviewed sources do not document a death.

All ten selected portraits were visually inspected. The first Ramin Roshandel candidate was a promotional graphic with text and was replaced by the plain portrait on the same university page. The first Yaz Lancaster candidate was a very dark performance image and was replaced by the artist’s explicitly supplied press photograph.

## Unresolved Fields

- Viviana Dal Santo: birth year and full birth date remain unknown after substantive research.
- Yaz Lancaster: integer birth year remains blank because the current official biography requests 199x.
- Full birth dates remain unknown for Marc Mellits, Marie-Hélène Fournier, Ramin Roshandel, Shelley Washington, and Victoria Cheah.
- Photographer names remain unknown for Marc Mellits, Ramin Roshandel, Viviana Dal Santo, and Yvette Audain. Public captions name the verified source instead.

## Validation

Each edited note was parsed as YAML. Only nationality, born, photo, and photo-source properties changed. All other properties, titles, slugs, and existing body content were preserved. Each note retains its Composer Works Base embed. Each portrait is a local JPEG with a maximum dimension of 600 pixels. Smaller source portraits were not enlarged. No full build, commit, or push was run by this batch.
